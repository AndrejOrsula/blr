Rust build dependency notices

This index follows the locked Cargo dependency graph for the wasm32-unknown-emscripten runtime build, including the statically linked scene bridge. Package license expressions come from package metadata; links point to license, notice, or copyright files shipped with the exact crate versions when those files were present. Additional scene bridge dependency notices cover the newly added crates.

This is a dependency-notice inventory, not a byte-level map of which package code appears in the final WebAssembly binary or a compliance certification. Files marked missing were absent from the installed crate source. The older blr-browser-probe wrapper has no package license expression; the scene bridge declares MIT OR Apache-2.0. Source review and publication remain pending.
