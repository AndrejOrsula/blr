Runtime license notices

This page identifies license materials for the browser demo’s Blender 5.2.0 and CPython 3.13.13 runtime, the statically linked Rust component, and the browser viewer.

Source status: Source publication is pending review. No Rust source code is included here, and no source availability or GPL compliance claim is made.

blr

The project’s first-party license texts are available as Apache-2.0 and MIT. The browser runtime contains a statically linked Rust component built from the project and its Rust dependency graph.

The detailed index records the locked WebAssembly-target package names, versions, declared license expressions, and the license or notice files shipped with each exact crate version when present. It also includes Rust standard-library notices and the Emscripten license. Missing package files and the build wrapper’s undeclared license are identified in the index.

  • Rust package, standard-library, and Emscripten notices

The index describes the build dependency graph. It does not map object code in the final binary or certify compliance for the combined runtime.
