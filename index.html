03 / What this is

Rust in.
Blender out.

Rust examples compile to bounded scene commands. Python examples execute in Blender's embedded Python runtime with access to bpy and the current scene. A successful Rust or Python run replaces the previous generated scene; separately created Blender objects remain outside that lease. Canceling a dispatched Python run closes Blender because Python code cannot be safely interrupted. Snapshot / Update GLB exports the generated objects. The preserved headless path also creates GLB previews.

Programs use the visible blr_demo.rs helper, which supports six primitive kinds, transforms, tint metadata and up to 64 objects. It uses Rust's bundled standard library, not private native blr sources or arbitrary Cargo dependencies. Blender's Workbench viewport uses gray Solid shading; the GLB snapshot turns tint metadata into browser materials. These views do not provide EEVEE or Cycles rendering. Compiler and Blender assets load only after you start the editor or run a program.
