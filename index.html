03 / What this is

Rust in.
Blender out.

The editor compiles a bounded Rust guest for WebAssembly and sends its scene-command output to a fresh Blender runtime frame. Blender and blr create the mesh; the browser viewer maps scene colors to preview materials and displays the returned world-space geometry with browser lighting.

Editable programs use the visible blr_demo.rs helper, a limited browser authoring API. They can use Rust's bundled standard library, but not native blr library sources or arbitrary Cargo dependencies. Those private sources stay private. Scene colors become browser preview materials, and browser lighting does not reproduce Blender's renderer or desktop interface. Compiler and Blender assets load only after you run the program.
