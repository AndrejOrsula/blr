02 / What this is
Blender, without the window.

      

        
This is an experimental headless build of Blender 5.2.0 with blr’s Rust callback. Your selected size is used to create one cube; the result reports scene geometry and version information.

        
It does not provide the Blender desktop interface, a renderer, or an editor for arbitrary Rust code. Browser runtime files are readable; no Rust source is included on this page.
